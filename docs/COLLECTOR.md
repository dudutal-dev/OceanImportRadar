```bash
pip install requests beautifulsoup4 lxml
```

לעמודים שנטענים ב-JavaScript (נמל הדרום, נמל חיפה):

```bash
pip install playwright
playwright install chromium
```

---

## 2. כיול המקורות — פעם אחת, לפני הריצה הראשונה

אתרי הנמלים משנים מבנה. לפני שמפעילים מקור, בודקים מה יש בעמוד:

```bash
python il_port_collector.py --inspect ashdod_expected
```

הפלט מראה כל טבלה בעמוד, את שורת הכותרת שזוהתה, ואת מיפוי העמודות. אז:

- **הטבלה זוהתה נכון** → הפעל `"enabled": true` ב-`sources.json`
- **"אין טבלאות ב-HTML הגולמי"** → העמוד נטען ב-JS. שנה ל-`"render": true`
- **כותרת לא זוהתה** → הוסף את המילה ל-`column_keywords` ב-`sources.json`

נמל אשדוד וחנ"י מופעלים כברירת מחדל. נמל הדרום וחיפה כבויים — צריך לאתר את כתובת עמוד האניות המדויקת ולעדכן.

---

## 3. ריצה

```bash
python il_port_collector.py
```

מה קורה: מושך את כל המקורות → מזהה טבלאות → ממפה עמודות → משווה מול הריצה הקודמת → כותב `radar_feed.json` ו-`sailings.csv`.

הפלט מדפיס כל הזזת ETA שזוהתה:

```
זוהו 3 הזזות ETA:
   MSC ALTAIR (אשדוד): 2026-08-27 → 2026-08-30
```

**זה הלב של המערכת.** ה-ETA הראשון שנראה נשמר כ-baseline מוצהר לצמיתות; כל עדכון אחריו נרשם כהזזה. אחרי חודשיים יש לך מדד אמינות אמיתי לכל ספן — מספר שאף אחד לא מפרסם לישראל.

## 4. חיבור לאפליקציה

**דרך א' (מומלץ) — שרת מקומי:**

```bash
python -m http.server 8080
```

פתח `http://localhost:8080/ocean-import-radar.html` → לשונית «נתונים» → **רענן מהפיד**.

**דרך ב' — בלי שרת:** פתח את ה-HTML בדאבל-קליק → «נתונים» → **טען קובץ פיד** → בחר `radar_feed.json`.

**במובייל:** שלח לעצמך את שני הקבצים, פתח את ה-HTML בדפדפן וטען את הפיד. הנתונים נשמרים ב-localStorage של המכשיר.

## 5. אוטומציה יומית

**Windows — Task Scheduler:**

```
Program:   python
Arguments: C:\ocean-radar\il_port_collector.py
Start in:  C:\ocean-radar
Trigger:   כל יום 06:30
```

**Mac / Linux — cron:**

```bash
crontab -e
30 6 * * * cd /path/to/ocean-radar && /usr/bin/python3 il_port_collector.py >> run.log 2>&1
```

פעם ביום מספיק. שתי ריצות ביום (בוקר וערב) יתפסו הזזות ETA מהר יותר.

## מגבלות — קרא לפני שאתה סומך על זה

- **גירוד הוא שביר.** שינוי מבנה באתר נמל שובר את המקור. הסקריפט מזהה טבלאות לפי תוכן ולא לפי selectors, אז הוא שורד שינויי עיצוב — אבל לא מעבר לטעינת JS או שינוי שמות עמודות. `--inspect` הוא כלי התיקון.
- **בדוק את תנאי השימוש** של כל אתר לפני הרצה מתוזמנת. ההשהיה בין מקורות מוגדרת ל-3 שניות; אל תוריד אותה.
- **AIS באזור שלנו לא אמין** — שיבושי GPS ואניות שמכבות משדר. לכן הסקריפט מסתמך על דוחות הנמלים ולא על AIS. `ATA` מדוח הנמל תמיד גובר.
- **אין כאן לוחות הפלגה מהספנים.** מה שיש זה מה שנוגע בישראל בפועל. Transit time מנמל המוצא צריך להיזון ידנית בלשונית «קווי יבוא», או לחכות לשלב ב' עם API בתשלום.
