# Ocean Import Radar · רדאר יבוא ימי

מערכת מעקב אחר אניות מכולה בדרכן לנמלי ישראל — לשימוש מנהל סחר ביבוא ימי.
בנויה כולה על מקורות מידע חינמיים, ללא מנוי לאף פלטפורמה מסחרית.

**מה היא נותנת שאין בשוק:** מדד אמינות לוחות זמנים לכל ספן בקו לישראל.
הסקריפט נועל את ה-ETA הראשון שנראה לכל אנייה כ-baseline מוצהר, ורושם כל הזזה אחריו.
אחרי חודשיים של ריצה יומית יש בידך מספר שאפשר להביא לשולחן המו"מ מול ה-buy rate.

## מבנה

| קובץ | תפקיד |
|------|-------|
| `index.html` | האפליקציה — קובץ יחיד, עברית RTL, עובד אופליין, נתונים ב-localStorage |
| `il_port_collector.py` | איסוף אוטומטי מאתרי הנמלים → `radar_feed.json` |
| `sources.json` | הגדרת המקורות ומילות המפתח למיפוי עמודות |
| `docs/COLLECTOR.md` | מדריך התקנה, כיול מקורות ותזמון |

קבצי הפלט (`radar_feed.json`, `history.json`, `sailings.csv`) ב-`.gitignore` —
הם נתונים תפעוליים ונשארים מקומית.

## הפעלה מהירה

```bash
git clone https://github.com/<user>/OceanImportRadar.git
cd OceanImportRadar
pip install -r requirements.txt

python il_port_collector.py --inspect ashdod_expected   # כיול חד-פעמי
```

## מסכים

- **רדאר** — סקופ סונאר קוטבי: טווח = ימים ל-ETA, סקטור = נמל פריקה, בליף לכל אנייה. לצידו רשימת הגעות קרובות וציר זמן 21 יום
- **הפלגות** — טבלה מלאה עם מיון, חיפוש וסינון; הופכת לכרטיסים במובייל
- **אמינות ספנים** — ETA מוצהר מול הגעה בפועל, לפי ספן ולפי שירות
- **קווי יבוא** — מטריצת שירותים: transit, תדירות, נמל שיתוף
- **עומס נמלים** — מעקב שבועי לחיזוי סיכון D&D
- **התראות** — הזזת ETA מעל סף, חריגה ללא דיווח הגעה, דילוג על נמל, קפיצה בתור
- **נתונים** — פיד אוטומטי, ייבוא ידני, גיבוי ושחזור

## מגבלות

- גירוד אתרים שביר מטבעו. הסקריפט מזהה טבלאות לפי תוכן ולא לפי selectors, ולכן שורד שינויי עיצוב — אבל לא מעבר לטעינת JS. `--inspect` הוא כלי התיקון.
- בדוק את תנאי השימוש של כל אתר לפני הרצה מתוזמנת. ההשהיה בין מקורות: 3 שניות.
- AIS באזור המזרח התיכון סובל משיבושי GPS ומאניות שמכבות משדר. לכן המערכת מסתמכת על דוחות הנמלים; `ATA` מדוח הנמל תמיד גובר.
- אין כאן לוחות הפלגה מהספנים — רק מה שנוגע בישראל בפועל. `transit time` מוזן ידנית בלשונית «קווי יבוא».
